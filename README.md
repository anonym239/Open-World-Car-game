# Project V-Mobile

Open-World-Actionspiel für Smartphones: Fahrzeug-Diebstahl (Car-Jacking), Fahrzeugphysik, Touch-Steuerung, dynamisches Wetter, Tag/Nacht-Zyklus. Das Repository enthält

1. **den technischen Master-Plan** (`docs/`) für die AAA-Produktion (Ziel-Engine: Unreal Engine 5, C++-Code-Skizzen), und
2. **einen spielbaren Vertical Slice** (`game/`, Godot 4.5, Mobile-Renderer). Ein GitHub-Workflow baut daraus bei jedem Push automatisch eine **Android-APK**.

> Ausführliche Dokumentation folgt unten und in `docs/`.
